# Tasty Burger — React + TypeScript

converted from the original fast-food HTML/CSS/JS template while keeping the original UI, icons, fonts, sections, and assets.

## Run locally

```bash
npm install
npm run dev
```

then open the localhost URL shown by Vite (normally `http://localhost:5173/`).

For a production build:

```bash
npm run build
npm run preview
```
